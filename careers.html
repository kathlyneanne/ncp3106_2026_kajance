01 / WHERE CAN CpE TAKE YOU?

Computer Engineering opens paths across the physical and digital sides of technology.

Graduates can work with computer hardware, embedded devices, software, networks, intelligent systems, cloud platforms, automation, technical support, and research and development.

02 / POSSIBLE CAREERS

ONE DEGREE.
MANY PATHS.

01

Computer Engineer

Designs, develops, integrates, and tests computer hardware and software systems for different computing applications.

SYSTEMS
02

Embedded Systems Engineer

Develops hardware and software built into devices such as appliances, vehicles, robots, controllers, and smart products.

EMBEDDED
03

IoT Engineer

Creates connected devices that use sensors, microcontrollers, networks, and cloud services to collect and exchange data.

CONNECTED
04

Software Engineer

Designs, develops, tests, and maintains software applications and systems that solve user and organizational needs.

CODE
05

Hardware Engineer

Designs and tests processors, circuit boards, computer components, electronic interfaces, and related hardware systems.

HARDWARE
06

Network Engineer

Plans, configures, maintains, and troubleshoots computer networks to keep devices and services reliably connected.

NETWORKS
07

Systems Engineer

Integrates hardware, software, networks, and other technical components into complete systems that meet defined requirements.

INTEGRATION
08

Cybersecurity Engineer

Helps protect systems, networks, devices, and data by applying security controls, monitoring threats, and addressing vulnerabilities.

SECURITY
09

Data Engineer

Builds and maintains systems and pipelines that collect, organize, transform, and prepare data for analysis and applications.

DATA
10

AI / Machine Learning Engineer

Develops systems that use data, algorithms, and machine-learning models to recognize patterns, automate tasks, and make predictions.

AI / ML
11

Cloud Engineer

Designs, deploys, and maintains computing services and infrastructure hosted on cloud platforms.

CLOUD
12

DevOps Engineer

Improves how software is built, tested, deployed, and maintained by connecting development and operations through automation.

DEVOPS
13

Robotics Engineer

Combines electronics, sensors, programming, control, and computing to develop robots and automated machines.

ROBOTICS
14

Technical Support Engineer

Diagnoses hardware, software, network, and system problems and provides technical solutions to users or organizations.

SUPPORT
15

Research & Development Engineer

Investigates new technologies, builds prototypes, performs experiments, and develops improved computing products or systems.

R&D
